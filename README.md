# UnityBridge AI v0.1.0 (Release, In Testing)

Мост, который подключает AI-сайты (arena.ai и любые другие) к Unity прямо из браузера — по аналогии с ZeroScript, но для Unity.

## Как это работает

```
[AI-сайт: arena.ai] --кнопка "⚡ Unity"--> [расширение браузера] --ws--> [мост в программе] --ws--> [Unity Editor]
                                                                        <-- ответ обратно на страницу --
```

1. **Программа** (`app/`, Electron) поднимает локальный мост `ws://127.0.0.1:17777/ws` и показывает дашборд: статус Unity, лог запросов, автоустановку расширения.
2. **Расширение браузера** (`extension/`, Manifest V3) на любом сайте добавляет рядом с текстовыми полями кнопку «⚡ Unity». По клику открывается панель запроса, ответ можно вставить обратно в поле.
3. **Расширение Unity** (`unity/UnityBridgeAI/`, скопируйте в `Assets/`) открывает окно *Window → UnityBridge AI*, подключается к мосту и выполняет запросы (создание объектов и т.д.).

## Установка

```bash
npm install        # зависимости программы
npm start          # запустить программу (мост + окно)
npm test           # smoke-тесты моста
```

- Расширение в браузер: нажмите «Установить расширение во все браузеры» в программе **или** вручную: `chrome://extensions` → режим разработчика → «Загрузить распакованное» → папка `extension/`.
- В Unity: скопируйте `unity/UnityBridgeAI` в `Assets/`, откройте *Window → UnityBridge AI*.

## Безопасность

Мост слушает только `127.0.0.1`, проверяет `Origin` и одноразовый токен на каждое подключение. Удалённые сайты не могут достучаться до Unity.

## Структура

- `app/` — десктопная программа (Electron): мост, автоустановка в Chrome/Edge/Opera/Brave/Yandex/Firefox, UI
- `extension/` — расширение браузера (MV3)
- `unity/` — C#-код для Unity Editor
- `tests/` — автотесты моста
- `docs/` — архитектура и руководство по тестированию
