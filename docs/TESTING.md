# Тестирование v0.1.0

## Автоматические тесты

```bash
npm install
npm test
```

Покрывается: запуск моста, `/health`, отклонение чужого Origin, отклонение неверного токена, рукопожатие Unity, полный цикл prompt→response, отклонение запроса без Unity, невалидный JSON.

## Ручное тестирование

1. `npm start` — программа открывается, мост на `ws://127.0.0.1:17777/ws`.
2. Вкладка «Браузеры» → «Найти браузеры» → «Установить расширение».
3. Перезапустите браузер, откройте https://arena.ai — у поля ввода появляется кнопка «⚡ Unity».
4. В Unity: скопируйте `unity/UnityBridgeAI` в `Assets`, откройте *Window → UnityBridge AI* — статус «Подключено ✅».
5. На сайте нажмите «⚡ Unity», введите «создай куб» → в Unity появляется куб, на странице — ответ.
6. Проверьте popup расширения: мост онлайн, Unity подключён.
